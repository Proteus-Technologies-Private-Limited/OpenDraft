Backups & Recovery

Timestamped copies of your script in a folder you choose, and getting your work back when something goes wrong.

What Backups Are

While you write, OpenDraft can save timestamped copies of your script into a folder you pick — on your computer, or in Files, iCloud Drive, Google Drive or Dropbox on a phone or tablet. Each copy is a complete .odraft file holding the script and its notes, tags, beats, character profiles and images.

Backups live outside the app’s database, which is the whole point: they survive even if something happens to the app itself.

ℹ️

Backups vs Version History: Version History stores checkpoints inside OpenDraft, covers a whole project, and is something you create deliberately with a message. Backups are ordinary files outside the app, one per script, written on a timer without you doing anything. Use both.

Turning Backups On

  1. Go to File > Backups > Backup Settings (or open Settings and scroll to Automatic Backups).
  2. Choose a folder. On the desktop, use Browse… to pick one or Use Default for an OpenDraft Backups folder in Documents. On iPad, iPhone and Android, tap Choose Folder… and pick a folder in Files (iCloud Drive, Google Drive and Dropbox all work).
  3. Tick Back up my work automatically.

The first copy is written the moment you turn it on, so you can look in the folder straight away and see that it works. Underneath the folder box, OpenDraft tells you whether it can write there and how many backups are already in it.

💡

On a phone or tablet, pick a folder outside the app — somewhere in Files, iCloud Drive, Google Drive or Dropbox. A folder inside the app would be deleted with it if OpenDraft were ever removed or reinstalled, which is exactly the situation backups are for.

What You Can Change

SettingWhat it does
Back up everyHow often a copy is written, from 5 to 60 minutes. Nothing is written when the script has not changed since the last copy.
KeepHow many automatic copies to keep per script — older ones are deleted as new ones arrive. Choose All backups to keep every copy. Backups you make yourself with Back Up Now are never deleted automatically.
Include images in backupsEmbeds the images your script references, so a restored script comes back complete. Backups are larger; without it, images in a restored script are missing.
Also back up documents I haven’t saved yetCovers screenplays you imported or started but never saved into a project — the ones nothing else is protecting.

On phones and tablets a copy is also written whenever you leave OpenDraft, before the system suspends the app. The timer alone is not enough there, because a suspended app can be shut down without ever running another one.

Where Backups Are Written

Inside the folder you chose, each project gets its own folder, so you can find the right script without reading filenames. Screenplays that do not belong to a project go in Unfiled Documents. Filenames carry the title, the date and time, and whether you made the copy yourself:

OpenDraft Backups/
  Silent Sonata/
    The Long Goodbye_2026-07-27_143205_a1b2c3d4.odraft
    The Long Goodbye_2026-07-27_150000_a1b2c3d4.manual.odraft

The naming is the same on every platform, so a backup written on a Mac can be restored on an iPad and the other way round.

⚠️

On the desktop, prefer a local folder to one inside OneDrive, Dropbox or iCloud Drive: cloud sync can interfere with files as they are being written. OpenDraft warns you if it spots a OneDrive path. On phones and tablets the trade-off runs the other way — a cloud folder is the one place the files are safely outside the app.

Backing Up On Demand

File > Backups > Back Up Now writes a copy immediately, with no dialog. That is what makes it different from an export: an export is a file to send somewhere, while Back Up Now pins this moment in your safety net. Copies made this way are never deleted by the Keep limit.

ActionWhere it goesDeleted automatically?
Automatic backupYour backup folder, on a timerYes, past the Keep limit
Back Up NowYour backup folder, immediatelyNever
File > Export > OpenDraft (.odraft)Anywhere you chooseNever

Recovering A Backup

Go to File > Backups > Recover Backup. Backups are grouped by script, newest first, and selecting one shows a preview of what is in it before you commit to anything.

  • Open as New Script — creates a new script in the current project from the backup. Nothing is overwritten; this is the safe choice.
  • Replace Current Script — overwrites the script you have open, behind a confirmation. A copy of the current state is saved first, so this can itself be undone.
  • Import from a file — recovers a .odraft you moved somewhere else, or one that came from another machine.
  • Delete — removes the selected backup.
  • Reveal (desktop only) — shows the file in Finder or Explorer.

Recovering Unsaved Work

Separately from all of the above, OpenDraft keeps a snapshot of the document you are editing — even one that was never saved into a project — and offers it back if the app closes unexpectedly or the system shuts it down. You will see Recover unsaved changes? the next time you open OpenDraft, with the choice to Restore or Discard.

Restoring replaces what is currently in the editor; your last saved version stays untouched until you save again. Each window keeps its own snapshot, and you are asked at most once per launch.

If Something Goes Wrong

What you seeWhat to do
Folder not foundThe folder was moved, renamed or deleted. Choose it again, or use Create it on the desktop.
OpenDraft can’t write herePick a folder you own. On Android this usually means the permission was cleared — tap Choose Folder… and grant it again.
Automatic backups are pausedSeveral backups in a row failed, so OpenDraft stopped trying rather than nagging. Fix the folder and press Resume.
A warning about OneDriveCloud sync can interfere with files as they are written. A local folder is safer for backups.
