Keyboard Shortcuts

Quick reference for all keyboard shortcuts in OpenDraft.

ℹ️

Windows/Linux users: Replace ⌘ (Cmd) with Ctrl for all shortcuts.

File

ActionShortcut
New Screenplay⌘N
Save⌘S
Export as PDF / Print⌘P

Edit

ActionShortcut
Undo⌘Z
Redo⇧⌘Z
Select All⌘A
Find & Replace⌘F
Go to Page⌘G
Add Script Note (or open the note under the cursor)⇧⌘N

View

ActionShortcut
Enter or leave Focus Mode⇧⌘F
Leave Focus ModeEsc

Some browsers keep ⇧⌘N for a new private window, so in the web version add notes from the right-click menu or the toolbar instead. See Focus Mode and Creating a Note.

Open the element menu (anywhere)⌥⏎

The element menu shortcut is ⌥⏎ by default (AltEnter on Windows and Linux) and can be changed in Settings → Editing. The same page has a switch to stop Enter opening the menu on blank lines. See The Element Menu.

Macros

A macro is text you type often — CONTINUOUS, LATER, a location you return to, a character with an extension — inserted with one shortcut or from Edit → Insert Macro.

  • Create macros in Settings → Macros (or Edit → Insert Macro → Manage Macros…). Give each one a name, the text, and optionally a shortcut: click the shortcut box and press the keys.
  • Insert as: leave it on Text at the cursor to type the text where the cursor is. Choose an element type, such as Character or Scene Heading, and the macro turns an empty line into that element, or adds a new one after the current line.
  • A line break in a macro’s text becomes a line break in the script.
  • If a macro’s shortcut is one the editor already uses (bold, the element shortcuts), the editor’s command keeps that key. Settings warns when two macros, or a macro and the element menu, share a shortcut.
  • Inserting a macro is one step — ⌘Z takes it back out.
  • Macros are kept on this device. Use Export… and Import… in Settings to move them to another computer or share them. Importing adds to your list and skips macros you already have.

Tips

  • The element shortcuts (⌘1–8) are the most important to learn. They let you change element types without leaving the keyboard.
  • ⌘Z (Undo) is your safety net — use it freely.
  • ⌘F (Find) is useful not just for searching, but for navigating — type a character name to jump to their scenes.
  • You can also access keyboard shortcuts from Help > Keyboard Shortcuts inside the app.
