AI Assistant

An optional add-on that writes formatted lines and scenes into your script, using an AI model on a server you choose.

ℹ️

Off until you turn it on. The AI Assistant is an add-on: nothing about it appears in OpenDraft, and nothing is sent anywhere, until you switch it on. It doesn’t come with an AI service of its own. It talks to a model server you run or choose, such as Ollama, LM Studio, Unsloth Studio or llama.cpp on your own computer.

Turning It On

  1. Start your model server and load a model in it.
  2. Open Settings → Add-ons and switch AI Assistant on.
  3. The Turn on AI Assistant dialog explains, under What leaves your device, what the add-on sends. Fill in the settings and click Turn On.
SettingWhat to enter
Server typeOllama (its own API), or OpenAI-compatible for Unsloth Studio, LM Studio, llama.cpp and similar servers.
Server addressWhere the server listens. Usually http://localhost:11434 for Ollama, http://localhost:1234/v1 for LM Studio and http://localhost:8080/v1 for Unsloth Studio.
ModelThe name of the model to use, as your server lists it (the default is qwen2.5). An instruct model of 7B parameters or more gives the most reliable results.
API keyOnly if your server asks for one.

Click Test connection to check the settings. It lists the models the server offers, or tells you the server has none loaded yet. To change the settings later, click Settings… beside the add-on in Settings → Add-ons.

In the desktop app, the server must run on the same computer (localhost or 127.0.0.1): the app’s security policy blocks plain http:// servers elsewhere on your network. To use a server on another machine, use OpenDraft in the browser.

Asking for Text

  1. Put the cursor where the new text should go. To rewrite a passage, select it.
  2. Open Tools > AI Assistant…. The Assistant panel opens beside the script.
  3. Type what you want and press Enter (ShiftEnter starts a new line). For example: Write a line for Ben: “Hello, everyone.” or Add a scene: INT. LAUNDRY - NIGHT, with an opening action. The empty panel offers a few examples to click.
  4. The assistant answers with a Proposal showing what it would add. Click Insert to put it into the script, or Discard.

The assistant writes through OpenDraft’s own editing commands, so its text arrives already formatted as scene headings, action, character cues, dialogue, parentheticals and transitions. It can add elements, change an element’s type, replace the selected text and insert plain text, and nothing else. Simple requests, such as a scene heading or a character saying a quoted line, are carried out straight away without asking the model.

Nothing changes in the script until you click Insert, and an insertion can be undone like any other edit. You can keep writing while a proposal waits. If you had text selected, the proposal follows it, and if you delete that text it tells you to ask again. A proposal is also dropped if a collaborator changes the script or you switch scripts. Click the bin in the panel header to start a new conversation.

What Is Sent

Each request sends the AI server your request, the selected text, the current scene heading and paragraph, and the lists of character names and scene headings. It does not send the whole script. With Ollama, the last few messages of the conversation go too. With a server on your own computer, nothing leaves your device.

The server address, model name and API key are stored on this device only, never in your scripts. The API key is kept unencrypted in the app’s storage, so use a key made just for this purpose.

Turning It Off

Switch AI Assistant off in Settings → Add-ons. Its menu item and panel disappear. Leave Also delete its saved settings, such as a server address or API key ticked to forget them as well.

Troubleshooting

  • “Set the AI server and model in Settings → Add-ons first.” — the server address or model is empty.
  • “Could not reach…” — check that the server is running at that address. In a web browser, Ollama must also allow the page’s origin: start it with OLLAMA_ORIGINS=*.
  • “The server requires an API key.” — copy the key from your server and paste it into API key.
  • “The model did not return a JSON action.” — rephrase the request, or use a larger model.
  • “The proposal is too large” — ask for less at a time; a proposal can hold up to 40 blocks.

Writing your own add-on? See Plugin & Add-on Development, which uses the AI Assistant as its worked example.
