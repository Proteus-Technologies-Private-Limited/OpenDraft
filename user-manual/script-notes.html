Script Notes

Attach annotations, reminders, and reference material to your screenplay.

Opening Script Notes

Open the Script Notes panel from View > Script Notes. Notes appear in a panel alongside the editor.

Creating a Note

  1. Select the text in your screenplay that you want to annotate.
  2. In the Script Notes panel, click + New Note.
  3. Type your note text.
  4. The note is anchored to the selected text — it stays connected even as you edit the script around it.

Note Colors

Notes are color-coded to help you organize different types of annotations:

ColorSuggested Use
● YellowGeneral reminders and to-dos
● RedIssues or problems to fix
● BlueResearch notes or references
● GreenApproved or completed notes
● OrangeFeedback from collaborators
● PurpleCreative ideas or alternatives

Click the color indicator on a note to change its color.

Embedding Media

Script notes can include more than just text. You can embed:

  • Images — Reference photos, mood boards, location scouting images.
  • Videos — Paste YouTube or Vimeo URLs for reference clips.
  • Asset references — Use the @AssetName syntax to link to assets in your project's Asset Manager.

Filtering Notes

When you have many notes, use the filter options to narrow down what you see:

  • By color — Show only notes of a specific color (e.g., just the "red" issues).
  • By element type — Show only notes attached to specific element types (e.g., just notes on dialogue).
  • By scene context — Show notes for the current scene or a specific scene.

Note Visibility

Toggle note highlighting in the editor via View > Note Highlights. When enabled, annotated text is highlighted with the note's color. When disabled, the text looks normal but notes are still accessible from the panel.

💡

Tip: Turn off note highlights when you want to read the script cleanly. Highlights are a working aid — they never print. A note only reaches the page if you set it to print, as below.

Printing a Note as a Footnote

Sometimes a note belongs in the script rather than beside it — a source for a quoted line, a permission, a reference you need on the page. Any script note can be promoted to a printed footnote or endnote.

  1. Write the note text (an empty note cannot print).
  2. Choose where it goes from the dropdown on the note in the Script Notes panel:
ChoiceWhat happens
Do not printThe note stays a working annotation. This is the default.
Page footerThe note prints at the foot of the page its reference sits on.
End noteThe note prints on a NOTES page at the end of the script.

Either way a superscript number appears in the script at the end of the annotated text, and the note's header shows Footnote 3 or Endnote iii. Numbering follows document order and runs as a single sequence whichever destination each note has, so inserting a note earlier in the script renumbers the ones after it.

Every note follows the document's own Location setting until you choose otherwise. Pick a destination that differs from it and that note keeps its own choice; the rest still move when you change the document setting.

Printing a General Note

General notes can print too, from the same dropdown — but they only offer Do not print and End note. A general note is attached to the file rather than to a line of it, so there is no text to carry a reference number and no page it belongs to. It can only ever collect at the end, whatever the document's Location says.

General notes are numbered after the anchored ones, continuing the same sequence, and a note's title prints above its text.

💡

Nothing changes until you ask it to. Notes do not print by default. While no note is set to print, your script paginates and exports exactly as it always has.

Footnote and Endnote Settings

Open Format > Footnotes & Endnotes…, or click the gear in the Script Notes panel header. The settings apply to the whole document.

SettingWhat it does
Print notes in the screenplayThe master switch. While it is off, notes stay on screen only.
LocationWhere notes go by default — Footnotes at the bottom of the page carrying the reference, or Endnotes on their own NOTES pages at the end. Any note can be sent the other way from its own dropdown.
Number format1, 2, 3 · a, b, c · A, B, C · i, ii, iii · I, II, III · *, †, ‡, §
Marker styleA superscript number, or a bracketed one like [1].
Start atThe number the first note carries.
NumberingContinuous through the script, or restarting on each page. (Endnotes are always continuous — there is no page to restart on.)
Include notes when exportingTurn it off to send a clean file without changing anything on screen.

Long Footnotes

A footnote longer than the room its page can spare is split, exactly as Word splits one: as much as fits prints at the foot of the page, and the rest continues at the foot of the next page — without repeating the number. A note that is still unfinished when the script runs out of pages finishes on the NOTES pages at the end, so nothing is ever cut off.

No page gives up more than half of itself to footnotes, so the script always keeps the greater part of every page.

⚠

Footnotes take room from the page. A footnote occupies lines at the foot of the page it belongs to, so page breaks move and your script can run longer — which matters when a page is roughly a minute of screen time. Endnotes leave the script's own pages untouched and add sheets at the end instead.

What Each Format Supports

FormatPrinted notes
PDFFull support — placement, number format, marker style, start number and per-page numbering, exactly as shown on screen.
Word (.docx)Real Word footnotes and endnotes, which Word lays out and reflows itself — each note keeps the destination you chose. Word uses its own numbering, so a script set to roman numerals still reads 1, 2, 3 there. General notes close the document under a NOTES heading, since nothing references them.
Final Draft (.fdx)The citation travels as a Final Draft script note. Final Draft has no footnote, so it appears in the Notes pane rather than on the page.
Fountain, Fade InNot supported — neither format has any footnote concept.
Browser PrintUse PDF export instead. Browser printing does not reproduce page furniture; headers and footers are lost there too.

Notes with Images

A printing note that contains an image reserves room for it on the page and prints it in the PDF. Video links print as their address — a page cannot play anything. An @AssetName reference that cannot be resolved prints as the text you typed, so nothing silently disappears.
