Spell Check

Catch typos and spelling errors as you write.

Enabling Spell Check

Toggle live spell checking via Edit > Spelling & Grammar > Auto Spell Check. For a manual proofreading pass, choose Spell Check… in the same submenu or press F7.

When enabled, misspelled words are underlined with a red squiggly line in the editor.

Spellcheck Languages

Open Edit > Spelling & Grammar > Spellcheck Languages to choose the dictionaries used by this script. The list includes every available dictionary language, including Polish, and any dictionaries installed from a custom URL.

  • A checkmark means the language is selected for this script. Click an installed language to enable or disable it. Keep several enabled for a multilingual script; at least one installed dictionary must remain active.
  • A checked language marked Not installed can be unchecked without downloading it. It will not check words until installed. Unavailable custom language codes also remain listed so you can remove them.
  • Languages marked Install download when selected, then become active and turn on live spell checking. The first download needs an internet connection; installed dictionaries are cached locally.
  • Enabling an installed language also turns on live spell checking. To switch to Polish alone, enable Polish (Polski), then disable English (US).

If you switch scripts while a dictionary downloads, it is installed for later use without being enabled in the new script. Saving the current script during a download does not cancel activation.

Language choices mark the script as unsaved and use its normal save settings. They are independent of the app's interface language and dialogue voice settings. Removing the last working downloaded dictionary restores bundled English, even if other enabled languages are not installed. To remove downloads or install a dictionary from a custom URL, use Grammar & Spelling Settings > Dictionaries in the same submenu.

Fixing a Misspelled Word

  1. Right-click on the underlined word.
  2. The context menu shows spelling suggestions at the top.
  3. Click a suggestion to replace the misspelled word.

Custom Dictionary

Screenplays often contain character names, fictional places, and invented terms that aren't in the standard dictionary. You have two options for handling these:

  • Add to Dictionary — Right-click the word and select Add to Dictionary. The word will never be flagged again across all your projects.
  • Ignore — Right-click and select Ignore to skip this word for the current screenplay only. Ignored words are saved per document — they persist between sessions, so you won't be asked about the same word again in this screenplay.
ℹ️

Per-document vs. global: Add to Dictionary adds the word globally (applies to all scripts). Ignore adds the word to the current screenplay's ignore list only. This is useful when a word is correct in one script (e.g., a character name) but shouldn't be whitelisted everywhere.

💡

Tip: Add your character names to the dictionary early on. This keeps the spell checker from flagging them throughout your script and lets you focus on real typos.

When to Use Spell Check

Some writers prefer to write freely first and check spelling later. Others want real-time feedback. OpenDraft supports both approaches:

  • While writing: Keep spell check on to catch typos as they happen.
  • After writing: Turn it off while drafting, then enable it for a proofreading pass.
