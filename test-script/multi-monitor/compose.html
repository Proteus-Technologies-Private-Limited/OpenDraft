Behaviour

What the panel window should do.

  • Remembers its display, position and size, and reopens there next time. If that display is unplugged, it opens on the main one.
  • Belongs to one script. Closing the main window closes its panel windows.
  • Any panel, several at once: e.g. Navigator on display 2, Page View on display 3.
  • Follows the theme and language of the main window.
  • Desktop first (macOS, Windows, Linux). Tablets can follow later.
